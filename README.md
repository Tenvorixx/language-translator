# 🌐 Language Translator Tool

A simple and user-friendly **Language Translator Tool** built using **HTML, CSS, and JavaScript**.

The application allows users to enter text, select source and target languages, and translate the text easily. It also includes features such as file upload, translated text download, and dark mode.

## ✨ Features

* 🌍 Translate text between multiple languages
* 🔄 Auto-detect source language
* 📝 Easy-to-use text input and output areas
* 📁 Upload text files for translation
* 📥 Download translated text
* 🌙 Dark mode
* ⌨️ Keyboard shortcuts
* 📱 Responsive and clean user interface

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and functionality
* **Google Translate API endpoint** – Text translation

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Make sure the folder structure is maintained.
4. Open `index.html` in your web browser.
5. Select the source and target languages.
6. Enter the text you want to translate.
7. Click the translate button.
